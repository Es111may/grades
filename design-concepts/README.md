## Решения, принятые в итерациях (не переспрашивать)

- Монументальный грейд (огромное слово) — НЕ делаем (v2-фидбек).
- 9-Box дизайнерам не показываем; лид и админ видят (v2).
- Заголовок «Команда» по центру, без eyebrow и подстроки (v3).
- Роли — в дропдаун; Все/Мои и вью-свитчер остаются сегментами (v3).
- Поиск + «Добавить» — в той же строке контролов (v3).
- Дату публикации — из шапки в грейд-панель (v3).
- Цифры пропорциональные (tnum off) — уже в проде (0.34.1).
- Тумблер светлой/тёмной темы остаётся; концепты рисованы под тёмную,
  при переносе проверять обе темы (токены уже per-theme).
