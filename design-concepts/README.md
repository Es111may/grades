## Чек-лист переноса — «Команда» (/admin/users)

- [ ] Шапка страницы: только «Команда», по центру, крупно (~64px).
      Убрать всё лишнее над/под заголовком.
- [ ] Один ряд контролов: [Все/Мои] · [Роль: дропдаун (Все/Дизайнеры/
      Стардизы/Лиды/Админы + счётчики)] · [вью-свитчер как есть] ·
      [поиск] · [кнопка «Добавить» (лайм)].
- [ ] Bento-агрегаты над лидербордом (4 ячейки, бары прижаты к низу):
      1) NIPC / Dream Team Index — conic-кольцо, формула Pavel:
         (звёзды + выс.потенциал + выс.производительность − зоны риска −
         ошибка подбора) / все дизайнеры; данные из TeamMatrixCell.
      2) «В срок» команды (медиана 6 мес) + мини-спарклайн.
      3) «Скорость роста»: медианный прирост XP за цикл + сколько
         дизайнеров в ≤20 XP от повышения (решено 10.07 вместо
         «XP команды» — тот был бесполезен). Данные: разница totalXp
         между соседними published-оценками, медиана по команде.
      4) Прогресс сезона: оценено N из M + черновики.
- [ ] Подиум топ-3: карточки с conic-кольцом по score вокруг аватара,
      score крупно, мини-бары UI/UX/PRD/IND/RES. №1 — лаймовая кромка+глоу.
- [ ] Таблица: статус вместо пустых «—» — чип «черновик · ждёт публикации»
      (оранжевый) / «не оценена» (серый); данные уже есть (status=draft).
- [ ] Блок «Карта потенциала» (9-box счётчики по ячейкам) + лента
      «Требует внимания» (черновики без движения, просевший «в срок»,
      кандидаты на повышение — правила придумать при переносе).

## Решения, принятые в итерациях (не переспрашивать)

- Монументальный грейд (огромное слово) — НЕ делаем (v2-фидбек).
- 9-Box дизайнерам не показываем; лид и админ видят; СТАРДИЗ НЕ ВИДИТ (v4).
- Рост vs медиана команды — виден admin/lead/stardiz на портрете (v4).
- «XP команды» в bento заменён на «Скорость роста» (v4).
- Заголовок «Команда» по центру, без eyebrow и подстроки (v3).
- Роли — в дропдаун; Все/Мои и вью-свитчер остаются сегментами (v3).
- Поиск + «Добавить» — в той же строке контролов (v3).
- Дату публикации — из шапки в грейд-панель (v3).
- Цифры пропорциональные (tnum off) — уже в проде (0.34.1).
- Тумблер светлой/тёмной темы остаётся; концепты рисованы под тёмную,
  при переносе проверять обе темы (токены уже per-theme).
